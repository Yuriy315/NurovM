**Лицензия:** MIT (или любая другая по вашему выбору)

## Описание программы

Простое кроссплатформенное приложение с графическим интерфейсом для учёта личных финансов.
Позволяет добавлять расходы с указанием суммы, категории и даты.
Ключевые возможности:
*   Добавление расходов.
*   Фильтрация по категории и дате.
*   Подсчёт общей суммы за выбранный период.
*   Сохранение и загрузка данных в формате JSON.
*   Валидация вводимых данных.
*   История операций в виде таблицы.

## Технологии

*   **Python 3.13 — основной язык.
*   **Tkinter** — стандартная библиотека для создания GUI (не требует установки).
*   **JSON** — формат хранения данных.
*   **Git** — система контроля версий.

## Как использовать

1.  **Установка**
    Убедитесь, что у вас установлен Python 3.8 или новее. Tkinter входит в стандартную библиотеку Python для Windows и большинства дистрибутивов Linux. Для macOS может потребоваться установка `python3-tk`.
    ```bash
    python3 -m pip install --upgrade pip  # Обновление pip (рекомендуется)
    ```
2.  **Запуск**
    Перейдите в папку проекта и выполните команду:
    ```bash
    python app.py
    ```
3.  **Работа с приложением**
    *   Заполните поля «Сумма», «Категория» и «Дата».
    *   Нажмите «Добавить расход».
    *   Используйте кнопки «Фильтровать» и «Сумма за период» для анализа данных.
    *   Данные сохраняются автоматически при нажатии на кнопку «Сохранить в JSON».
> **Примечание:** Файл с данными (`data/expenses.json`) находится в `.gitignore`. При первом запуске он будет создан автоматически.

## Примеры использования (Тесты)

1.  **Добавление расхода:**
    *   Сумма: `1500.50`
    *   Категория: `Продукты`
    *   Дата: `2026-05-06`
    *   Ожидаемый результат: Запись появилась в таблице.
2.  **Ошибка валидации:**
    *   Сумма: `-100`
    *   Ожидаемый результат: Появление окна с ошибкой «Сумма должна быть положительным числом».
3.  **Подсчёт суммы:**
    *   Нажмите «Сумма за период».
    *   Введите даты: с `2026-04-01` по `2026-04-30`.
    *   Ожидаемый результат: Отобразится сумма всех расходов за апрель.
4.  **Фильтрация:**
    *   Нажмите «Фильтровать».
    *   Введите категорию: `Транспорт`.
    *   Ожидаемый результат: В таблице останутся только расходы из категории «Транспорт».
